## 1. 产品概述

把 4.2 寸三色电子价签变成一块"想推什么就推什么"的桌面墨水屏：Windows 桌面应用编辑内容 → 离屏渲染 → 量化 → USB 一键推送到屏。

- **目标用户**：拥有 ESP32-C3 + SSD1619 价签屏的个人玩家
- **核心价值**：双击即用（免 Python/Node 环境）、所见即所推（预览与上屏同一 HTML）、19 个模板覆盖日常场景
- **硬件**：4.2 寸 400×300 红黑白三色墨水屏，调色板 2bpp `0=黑 1=白 2=黄 3=红`（本屏黄显示为红，换四色屏协议不改）

## 2. 传输与固件

### 2.1 通路

| 通路 | 状态 | 说明 |
|---|---|---|
| USB 串口（主） | ✅ 已交付 | 按 VID_303A/PID_1001 过滤，零配置永远可用；COM12，校准 cal=2 |
| WiFi（副） | 🔒 固件已含、默认关闭 | mDNS `inkpad.local` + HTTP POST `/frame`，M6 打通 |

### 2.2 串口协议（ASCII 命令 + 二进制帧，`\n` 结尾）

| 命令 | 设备回 | 说明 |
|---|---|---|
| `PING` | `PONG <ver>` | 探活 |
| `INFO` | `INFO w=400 h=300 bpp=2 invert=1 driver=ssd1619 mode=usb` | 应用据此决定画多大 |
| `FRAME <bytes> <crc32>` | `READY` → 发裸数据 → `OK`/`ERR` | 校验通过才落内存 |
| `SHOW <crc32>` | `SKIP` 或 `SHOWING… → DONE <ms>` | CRC 相同跳过，省 13.4s 全刷 |
| `TEST` | `DONE` | 四段测试图（黑条/白字 B/红条/棋盘） |
| `CAL 0\|1` | `OK` | 切极性存 NVS，立刻重刷 |
| `MODE usb\|wifi` | `OK` | 切通路存 NVS |
| `CFG ssid pass` | `OK` | 配网存 NVS，不重烧 |
| `BLANK` / `RESET` | `DONE` / — | 清白屏 / 重启 |

### 2.3 关键固件规则

- 刷屏前断开射频（WiFi 开着刷屏会干扰波形），刷完重连
- 驱动时序/极性/初始化序列照抄 `epd42_weather` 已验证实现（含"不要写 0x1A 覆盖温度"教训）

## 3. 渲染管线

```
HTML 模板（{{key}} 占位）→ Electron 离屏渲染 400×300
  → 三色量化（threshold 170 / Floyd–Steinberg 抖动）
  → 2bpp 30000 字节帧 + CRC32 → 串口/WiFi
```

预览与上屏用同一个模板 HTML（iframe 缩放），所见即所推。加风格 = 加 CSS。

## 5. 设计规范（0.3.0 起）

- **衬线字体栈**：`"Noto Serif SC", "Source Han Serif SC", "SimSun", serif`；英文单词/音标/数字 Georgia 优先。禁止 `"Microsoft YaHei", ..., serif` 混合栈（实际命中雅黑）
- **红色体系**：#d02020 点睛式分布，占比 0.1%~5%；hero 大数字、日期/出处、头部红线、打卡格、进度条填充（0.4.4 按用户要求加强：年进度大数字、待办百分比、金句出处、备忘录日期、今日历史头部线、日读进度条、相框说明线）
- **InkSight 设计语言**（对齐 [InkSight](https://www.inksight.site/zh/preview)）：顶部状态栏 + 底部 dashed 细线、页脚 label + "— 出处"、居中红色短分隔线（40~60px）、hero 大数字、垂直居中卡片布局
- **样式权威参照**：`.refs/inksight-modes/`（28 个模式布局 JSON，衬线字号/separator 宽度以此为准）
- **已知物理限制**：<14px 宋体衬线特征在 400×300 量化后丢失（视觉近似黑体），≥20px 可辨；小字发虚时该处回退黑体 `"Microsoft YaHei", sans-serif`

### 桌面 UI 设计规范（0.4.0 起）

- **Apple 浅色设计语言**：macOS 色板（#007aff 强调蓝 / #f5f5f7 窗口底 / #f2f2f7 输入底）、毛玻璃顶栏、iOS 灰底无框输入聚焦蓝环、macOS 胶囊分段控件、iOS 设置页式分组卡表单（.card + 行式分隔线）、6px 细滚动条、抽屉毛玻璃遮罩 + 弹入动画
- 侧栏模板列表可滚动（`min-height:0` + 幂等 DOM，切模板保滚动位置）；选中项蓝色胶囊
- 类名与旧版完全一致，只换皮——`ui/templates/*.html`（屏显模板）不引用 `ui/style.css`，两层样式互不影响



## 6. 应用功能清单

- 模板切换 / 表单编辑 / 预览放大（iframe 2 倍）
- 推送到屏幕（USB）、颜色校准向导、四段测试图
- 串口记忆自动重连（0.2.0）
- 天气：Open-Meteo 免 key、30 分钟缓存、离线降级标注（0.1.0 M4）
- 待办行式编辑器：勾选/紧急/删除/拖动排序（0.2.0）
- AI 卡片：服务商下拉（阿里云百炼默认/智谱 GLM/Kimi/DeepSeek/自定义，0.4.0），切换自动填 baseUrl/model 且可手改，模型带建议列表可手输；OpenAI 兼容，用户自带 key（0.2.0）
- 调试抽屉（日志）+ 顶栏状态反馈（主动作成败必须顶栏可见）

## 9. 明确不做（边界）

- ❌ 定时 / 轮播 / 托盘常驻 / 开机自启
- ❌ 登录、多用户、云端服务
- ❌ 自由拖拽排版
- ❌ 多设备同时管理（profile 已抽象，加时不用重构）
- ✅ AI 生成（0.2.0 起含 AI 卡片模板——修订原方案"云端内容源不做"：AI 生成做，但本地直连用户自己的 key，不做云服务）

## 10. 扩展尺寸预留

1. 固件 `INFO` 回报 `w/h/bpp/driver/invert`，应用不假设 400×300
2. 模板全用 CSS 变量 `--w/--h` 和相对单位，不写死像素
3. 设备 profile 一条 JSON：`{name, w, h, colors, driver, invert, safeMargin}`，加尺寸就是加一条
